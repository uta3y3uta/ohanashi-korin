# おはなしコロリン

即興でお話づくりを楽しむアプリ。

「いつ」「どこで」「だれが」「なにをした」の4つのサイコロでお話のはじまりを決め，
接続詞のサイコロを「次へ」ボタンで何度もふりながら，お話をつないでいきます。
「オチまであと〇回」がゼロになったら，自分でオチを考えてお話を完成させましょう。

## 公開URL

https://uta3y3uta.github.io/ohanashi-korin/

## 使い方

1. トップページで「オチまでのサイコロ回数」を決めて，「URLをはっこう」を押す
2. 発行されたURLを子供たちにシェアする
3. URLを開くと，すぐにあそべます

## ファイル構成

- `index.html` … トップ（設定）画面とプレイ画面の両方を持つSPA
- `style.css`  … スーパーマリオワールド風の見た目
- `app.js`     … 3フェーズ（はじまり決め→接続詞ループ→ふりかえり）の進行ロジック
- `data.js` / `data-where.js` / `data-who.js` / `data-what.js` / `data-connector.js` … 各カテゴリ250項目，ルビ付き
